# 🌍 Wanderlust – Airbnb Inspired Travel Listing Platform

Wanderlust is a full-stack web application inspired by Airbnb, built using the MERN ecosystem. 
The platform allows users to discover, create, manage, and review travel accommodations from various locations around the world.
The application provides a seamless user experience with secure authentication, property management, image uploads, reviews, and search functionality.
Users can browse listings, view detailed property information, add their own accommodations, edit or delete owned listings, and share feedback through 
reviews and ratings.

Built following the MVC architecture, Wanderlust integrates MongoDB for data storage, Express.js and Node.js for backend services, EJS for dynamic rendering,
Cloudinary for image management, and Passport.js for authentication and authorization.

## Key Features

- User Registration and Login Authentication
- Secure Authorization and Session Management
- Create, Edit, and Delete Property Listings
- Upload and Manage Property Images using Cloudinary
- Search Listings by Title, Location, or Country
- Review and Rating System
- Responsive and User-Friendly Interface
- Server-Side Validation and Error Handling
- MVC Architecture for Better Code Organization

## Tech Stack
